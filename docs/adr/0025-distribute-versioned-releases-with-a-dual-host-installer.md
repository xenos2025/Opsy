# 通过版本化发行和双宿主安装器分发

`opsy` 在 `xenos2025/Opsy` GitHub 仓库维护，并用带明确版本号的 GitHub Release 发布。仓库提供 `install.ps1` 与 `install.sh`：安装器自动检测 Codex、WorkBuddy 的 Skill 根目录，也允许运营者显式选择其中一个或两个宿主，把同一版本的 Skill 安装到所选位置。

安装或升级前必须校验发行包与当前版本、展示变更计划并获得确认；已有 Skill 先归档再替换，不进行无提示升级。安装器不得修改店铺运营工作区。卸载只移除共享 Skill，本地客户项目、店铺档案、月度数据、运营产物与写前备份必须保留。
