# 月度数据更新后自动刷新只读 404 队列

每次月度数据更新成功后，系统自动合并选填的 `gsc_not_found.csv`、上月未解决项和本月已知 handle 变化，去重并重新检查候选 URL 的当前响应，再生成 `outputs/404-review-YYYY-MM/` 下的只读待处理队列。队列记录候选来源、最近发现日期、数据新鲜度，并给出“可能重定向、修正来源、保留 404、忽略、待人工判断”的初步分类。

自动刷新不得创建、修改或删除 Shopify 重定向。缺少选填 404 数据时仍可保留遗留项或生成空队列，不视为错误。运营者必须主动进入“404 处理”，复核具体候选和目标并批准后，相关项才能进入 Shopify 写入门禁。
