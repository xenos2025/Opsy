# 聊天附件与商品资料文件夹进入同一商品流水线

商品运营同时支持两种初学者输入方式：运营者可以直接在 Codex 或 WorkBuddy 对话中发送图片、视频并补充基础信息，也可以把资料放入运营工作区的商品资料文件夹。商品资料文件夹是默认持久入口；Excel/CSV 仅用于可选的批量字段补充，不要求运营者编写 JSON、GraphQL 或固定 payload。

聊天附件不能只存在于临时对话上下文。系统必须在取得工作区写入条件后，将附件与运营者提供的基础事实整理到 `inbox/products/<batch>/<candidate>/`，保存来源记录，再交给与文件夹输入相同的商品队列、逐项校验、草稿创建和发布门禁。运营项目构建器因此必须创建商品收件箱；未完成候选商品归属的附件不得触发 Shopify 写入。

明确只有一个商品，或运营者已经通过型号、目录或消息分隔给出清晰归属时，可以自动建立候选项。一次输入包含多个商品或归属存在歧义时，系统必须先展示素材分组建议并等待确认；不得仅凭视觉相似度决定图片和视频属于哪个商品。未确认素材留在待整理区，不进入字段生成或商品草稿流程。
