# 只注册一个主 Skill，六项能力作为内部工作流模块

Codex 与 WorkBuddy 只安装和识别一个 `opsy` Skill。它提供唯一主入口，读取状态菜单并按运营者选择加载六个内部工作流：运营周报、商品运营、Blog 与内容、404 处理、上月数据查询/更新、连接与店铺档案。六个工作流和状态规则分别放在 Skill 根目录可直接引用的 `references/workflow-*.md` 与 `references/state-machine.md`；执行器、产物模板和测试分别放在 `scripts/`、`assets/` 与仓库级 `tests/`。

内部工作流不单独注册成用户可调用 Skill，避免多个描述同时触发、要求初学者选择 Agent 或在两个宿主中产生不同路由。模块仍须拥有独立输入、输出、校验和测试契约，使单入口不会退化成一个无法维护的超长提示文件。
