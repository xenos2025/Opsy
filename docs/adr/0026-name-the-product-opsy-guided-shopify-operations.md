# 使用 Opsy — Guided Shopify Operations 作为正式名称

产品正式名称为 **Opsy — Guided Shopify Operations**，中文名为 **Opsy Shopify 引导式运营助手**。`Opsy` 是 “Ops” 与 “easy” 的品牌化组合，也是仓库名、用户主入口和唯一注册 Skill 的统一短名；Skill 文件夹与 frontmatter 名称均使用小写 `opsy`。

统一短名让初学者可以直接通过 `$opsy` 启动，不需要记忆较长的技术名称，也避免项目名、发行包名与 Skill 名之间产生额外映射。描述字段负责明确 Shopify、B2B 询盘站和六项运营能力，以保持触发准确性。
