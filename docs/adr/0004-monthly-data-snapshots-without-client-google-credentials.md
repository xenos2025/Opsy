# 客户使用服务方推送的月度数据快照

基础运营套组不要求客户配置 Google 密钥或实时 GA4/GSC 连接。服务方每月把标准化数据文件推送到客户运营项目的 `data-center/`；当前有效文件保持在根目录，旧快照按月份归档，来源清单记录数据来源、范围、时区、更新时间、行数和字段。客户的“数据查询”只查询最新有效快照并明确显示数据新鲜度；“数据更新”负责校验新快照、归档旧快照并更新来源清单。

这一选择牺牲实时性，换取低门槛、可复现和不向客户分发 Google 凭据。没有有效快照时，功能必须显示数据待推送，不能用旧数据冒充上月数据，也不能编造实时结论。

客户取得月度快照有两种方式：仓库型项目通过受控 GitHub 快进更新拉取，非仓库或线下交付场景接收服务方直接发送的数据包。两种方式落地后都必须保持相同的 `data-center/`、`manifest.json` 与 `archive/YYYY-MM/` 契约，业务 Skill 不区分上游交付渠道。
