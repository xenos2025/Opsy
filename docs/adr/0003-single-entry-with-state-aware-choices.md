# 一个主入口，根据当前状态展示多个选择

运营者只使用一个主入口；主入口读取店铺连接、轻量建档和待审批操作等当前状态，再显示此刻允许执行的少量业务选择。用户可以回复编号，也可以直接描述目标。连接、建档、商品、内容、优化与复盘等专项 Skill 属于内部能力，不要求初学者理解 Runtime、Agent 层级或 Skill 名称。

状态菜单取代固定的大功能清单：店铺连接未完成时只显示业务问卷、公开站点检查和连接操作；已连接但未建档时优先完成建档；运营写入就绪后才显示对应运营能力；待批准写入必须单独显示预览与确认。这样保留用户选择权，同时避免展示当前不可执行或容易误操作的入口。

运营写入就绪后的一级选择确定为：运营周报、商品运营、Blog 与内容、404 处理、上月数据查询/数据更新、连接与店铺档案。运营周报以本周操作进度、待处理事项和下周任务为主体，月度数据只作辅助证据；没有覆盖本周的数据时不生成周度流量或转化趋势。运营项目文件夹构建属于初始化状态，不占用运营写入就绪后的一级菜单。
