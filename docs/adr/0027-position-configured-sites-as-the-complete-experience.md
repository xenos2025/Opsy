# 将配置连续性作为配套独立站的完整体验优势

Opsy 可以用于符合 V1 范围的 Shopify 独立站，但配套交付并完成标准配置的站点提供更完整的开箱体验。优势来自建站阶段已经建立并验证的元字段定义、发布对象、市场与语言约定、数据导出契约和运营工作区；这些配置在连接和轻量建档后可以直接、安全地进入日常运营。

公开说明必须同时写清每项能力的前置条件。非配套站点按实际建档结果开放已满足条件的功能，缺失项形成建站或数据交付清单；基础运营不得自行创建元字段定义，也不得在缺少有效数据快照时生成分析结论。

这一定位表达“配套站点体验更完整”，但不把 Opsy 描述成只能用于服务方交付站点的封闭工具。兼容性与能力就绪度必须分开说明。
