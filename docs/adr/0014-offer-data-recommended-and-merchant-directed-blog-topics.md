# Blog 同时支持数据推荐与客户指定主题

Blog 与内容菜单提供两个选题入口。存在最新有效月度数据快照时，系统可以结合数据与现有 Blog、商品页和商业页面，推荐最多三个候选主题，并显示数据月份、推荐依据、重复检查与关键词冲突风险。运营者也可以直接提供主题、问题、图片、产品资料或其他素材，不必等待月度数据。

数据缺失或过期时，系统默认使用客户指定主题并提示数据状态；不得编造搜索量、排名、趋势或机会分。两个入口都必须进入相同的内容工种与场景锁定、站内重复检查、五维工艺检查（正文/配图/表格/内链与 CTA）、B2B 询盘 CTA、事实确认、文章包校验、Shopify 草稿和二次发布确认流程。详见 ADR 0028。
